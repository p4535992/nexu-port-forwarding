# Dependencies and provenance

Application code was created for NexU Port Forwarding. NexU is the desktop integration reference; no signing-engine code or assets were copied. The application PNG/ICO was created for this project. No font files are bundled by this project.

Direct runtime dependencies declared in pom.xml: OpenJFX Controls 21.0.11; Dorkbox SystemTray 4.2.1; Apache MINA SSHD core 2.19.0; Bouncy Castle bcpkix-jdk18on 1.84; EdDSA 0.3.0; SLF4J Simple 2.0.17. JUnit Jupiter 5.12.2 is test-only. Maven resolves additional transitive libraries.

Dependency JARs are retained intact in the lib directory, including their embedded license/NOTICE resources. Native packages also retain the included Java runtime's legal directory. Consult each library's metadata and bundled notices for its applicable terms; this inventory is not a replacement for license texts or a legal/security audit.

No application-code license has been selected on the repository owner's behalf. The reference project's license is not automatically assigned to this independent project. Review the complete dependency/runtime notices and select the intended application license before public redistribution.

Releases do not contain user credentials, SSH private keys, user profiles or signing certificates. Native packages are unsigned community release candidates.
